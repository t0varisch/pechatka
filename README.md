# Печатка

Читай книги, печатая их. Текст бежит строкой, текущая буква стоит на месте; верная клавиша двигает строку, ошибка — мигает и не пускает дальше. Считает скорость (знаков в минуту) и точность, по каждой книге копит среднюю. Открывает FB2 (и fb2.zip), EPUB, TXT, PDF. Оглавление, закладки, темы, шрифты. Работает в браузере и ставится на телефон как приложение; книги хранятся только на устройстве.

Сестра читалки [«Точка»](https://github.com/t0varisch/tochka): та же библиотека и разбор книг.

## Правила набора

- «» печатаются как `"`, — и – как `-`, … как `...`; вместо «ё» можно «е»
- Конец абзаца (¶) — пробел или Enter
- Символы, которых нет на клавиатуре (©, буквы с ударениями), пропускаются сами
- В настройках можно не учитывать заглавные и не печатать знаки препинания
- Пауза дольше 3 секунд не портит скорость

## Разработка

```
npm install
npm run dev      # локально
npm test         # тесты
npm run build    # сборка в dist/
```
